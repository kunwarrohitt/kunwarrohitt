# Rohit Kunwar

**Full-stack engineer building data-driven fintech and marketplace products.**

I work across the stack to turn complex workflows and market data into reliable, usable software — with a focus on scalable backend systems, clean product experiences, and financial intelligence.

- Building **ARISE** — an equity intelligence platform for research, ranking, and stock-analysis workflows.
- Building multi-tenant service marketplace platforms with production-oriented architecture.
- Interested in Indian markets, financial data systems, system design, and product engineering.

## Selected work

### ARISE — Analytical Ranking & Intelligence for Strategic Equities
A stock-intelligence platform designed to organise market data, ranking models, scorecards, and equity research signals.

**Focus:** financial-data pipelines, scoring systems, PostgreSQL modelling, API design, real-time product interfaces.

### Multi-tenant Services Marketplace
A scalable marketplace architecture for connecting customers, service providers, and operations teams.

**Focus:** multi-tenancy, role-based access, booking workflows, backend modularity, and product-scale system design.

### Habit Tracking PWA
A focused progressive web app for building consistent habits through lightweight tracking and feedback loops.

**Focus:** responsive UX, PWA capabilities, state management, and performance.
